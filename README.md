# Expense Tracker (C++ / Qt)

This is a **desktop expense tracker application** built using **C++ and Qt**.  
The project helps users record and manage their daily expenses in a simple and organized way.

This project was created to practice **C++ Object-Oriented Programming** and to learn how a **Qt-based GUI** can interact with backend C++ logic.

---

## About the Project

The currently working version of this project is a **Qt GUI-based Expense Tracker**.  
The application allows users to add expenses, store them, and view summaries over time.

The backend logic is written in C++, while the frontend is built using **Qt Widgets** in **Qt Creator**.

---

## Features

- Add new expense entries
- Automatically records the date and time of each expense
- Stores expense data in a CSV file
- Loads saved data when the application starts
- Simple and user-friendly graphical interface
- Basic input validation to avoid incorrect entries

---

## Project Structure

The main working code is located in the `qtGUI/` folder.

Important files:
- `main.cpp` – application entry point
- `main_classes.cpp / .h` – core expense-related classes
- `auxillary.cpp / .h` – date and time handling
- Qt UI files created using Qt Creator

## How to Run the Project

1. Open **Qt Creator**
2. Open the project file (`.pro`) from the `qtGUI` folder
3. Configure the kit if prompted
4. Build and run the project
